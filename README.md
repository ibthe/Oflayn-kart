# Georgia Offline 🇬🇪

## Версия 0.5.2 — исправление установки PyOsmium и сохранение офлайн-справочника

- GitHub Actions устанавливает PyOsmium и проверяет реальный извлекатель на небольшом OSM XML fixture.
- Из того же проверенного country PBF строится `georgia-poi.sqlite` (search-index revision 2) с категориями: еда, жильё, достопримечательности, медицина, транспорт, сервисы, магазины, история, природа и населённые пункты.
- В SQLite сохраняются `name`, `name:en`, `name:ru`, `name:ka`, координаты и OSM-теги. Для поиска используется локальный нормализованный индекс `search_text`; сетевые запросы отсутствуют.
- Экран «Места» устанавливает SQLite asset в private storage по SHA-256 и позволяет искать по любому из трёх вариантов имени, адресу, телефону, сайту и часам работы; есть фильтры категорий и копирование координат. В карточке объекта отображаются включённые языки и публичные детали (адрес, телефон, сайт, часы работы, кухня, доступность), если соответствующие теги есть в OSM.
- База создаётся только из OSM nodes и closed ways; relation-only POI и геометрические центроиды сложных multipolygon пока не включены. Нет автоматического перевода отсутствующих имён. Контактные сведения, адреса и часы работы неполны, поскольку зависят от заполненности OSM.
- Полная генерация `georgia.map`, SQLite POI и сборка APK должны быть подтверждены GitHub Actions; локальные проверки кода не заменяют этот запуск.


Полнофункциональный автономный атлас Грузии для Android. Цель проекта — подробная карта всей страны, поиск, маршруты для автомобиля/4×4/велосипеда/пешком, путеводитель, топография, планировщик путешествий и локальные GPS-инструменты.

> **Статус разработки (0.5.2):** подключён Mapsforge renderer; добавлен CI-пайплайн, который получает OpenStreetMap PBF для Грузии (Geofabrik — основной источник, OpenStreetMap France — резервное зеркало), проверяет контрольную сумму, собирает Mapsforge `.map` с языковыми вариантами `en`, `ru`, `ka`, кеширует результат и встраивает его в debug APK. Первый полный реальный запуск workflow с текущей связкой `.map` + POI SQLite ещё должен подтвердить генерацию обоих наборов данных и сборку APK. Встроенная карта при обновлении APK сравнивается по SHA-256 и заменяется в приватном хранилище только если она изменилась; пользовательский импорт не перезаписывается. Сам бинарный файл карты не хранится в исходном ZIP/репозитории: GitHub Actions создаёт его во время сборки.

В приложении уже есть Compose-интерфейс, локальные настройки языков/тем, Mapsforge renderer, импорт локального `.map`, GPS-инструменты, компас, метка автомобиля и экран локального поиска по SQLite POI-базе на English/Russian/Georgian там, где имена присутствуют в OSM. POI-экстрактор CI индексирует узлы и замкнутые ways; relation-only объекты, маршрутизация BRouter, DEM/контуры, спутниковый слой, одновременные многострочные подписи всей карты и прямое хранение карты на SD-карте ещё требуют реализации.

## Принятые решения

- Kotlin + Jetpack Compose.
- Один APK; GitHub Actions формирует и встраивает бинарную карту в `app/src/main/assets/offline/` перед сборкой.
- Приложение не должно запрашивать сетевые разрешения; CI проверяет исходный и объединённый Android manifest.
- Без аккаунта, рекламы, аналитики и сетевой телеметрии.
- Карта готовится из OpenStreetMap country extract для Грузии; основной источник — Geofabrik, резервный — OpenStreetMap France; лицензия данных ODbL 1.0.
- Карта записывает доступные варианты названий `en`, `ru`, `ka`. В текущем UI Mapsforge выбирает один предпочтительный язык; одновременно выводить несколько строк названий пока нельзя. Отсутствующие в OSM языковые варианты не переводятся автоматически.
- Тема приложения: системная / светлая / тёмная. Стили карты: классический / рельеф / автомобильный / велосипедный.
- Внутреннее хранилище по умолчанию; выбор SD-карты через Storage Access Framework уже предусмотрен в UI, но реальное размещение больших файлов на SD-карте ещё требует реализации.

## Открыть и собрать проект

1. Открой папку репозитория `GeorgiaOffline` в Android Studio.
2. Используй JDK 21 (как в CI) и Android SDK Platform 36 / Build Tools 36.0.0.
3. Для локальной сборки без подготовленного файла карты можно выполнить `gradle :app:assembleDebug`; такой APK будет без карты страны.
4. Полная сборка с картой выполняется GitHub Actions после `Push` в `main`/`master` или вручную через Actions → Android CI → Run workflow.

В starter-архив не включён бинарный `gradle-wrapper.jar`. Если Gradle установлен, его можно создать командой `gradle wrapper --gradle-version 9.6.0 --distribution-type bin`. GitHub Actions использует закреплённый Gradle напрямую.

## Полная сборка с офлайн-картой

Workflow `.github/workflows/android-ci.yml` выполняет следующие действия:

1. Устанавливает Android SDK Platform 36 и JDK 21.
2. Проверяет исходный Android manifest на сетевые и фоновые location-разрешения, затем запускает предварительную проверку OSM URL, checksum-имени и сборки Map Writer.
3. Запускает Python unit tests для POI классификатора и схемы SQLite; затем выполняет Android unit tests.
4. Сначала восстанавливает последнюю проверенную пару `georgia.map` + `georgia-poi.sqlite` и общий build manifest из GitHub Actions cache.
5. Если данных нет или запрошено обновление, устанавливает Osmosis и PyOsmium. Для Osmosis собирается отдельный plugin JAR из Maven Central артефакта `org.mapsforge:mapsforge-map-writer:0.25.0`; для PyOsmium запускается настоящий extraction smoke-test на небольшом OSM XML fixture.
6. Скачивает OSM PBF: сначала Geofabrik, затем резервное зеркало OpenStreetMap France (`georgia.osm.pbf`, MD5 `georgia.osm.pbf.md5`). Каждый файл сверяется с MD5 того же источника.
7. PyOsmium извлекает POI узлы и закрытые ways в `georgia-poi.sqlite` с именами `name`, `name:en`, `name:ru`, `name:ka`; затем SQLite проверяется на integrity и количество записей.
8. Mapsforge создаёт `georgia.map` с `preferred-languages=en,ru,ka` и явным bbox в дисковом режиме `type=hd`. SHA-256 и размеры обеих баз попадают в `georgia-map-build.json`; оба файла кэшируются вместе.
9. Собирает APK и проверяет физическое наличие карты и POI базы внутри APK, их контрольные суммы и отсутствие сетевых разрешений в объединённом manifest.
10. Публикует `GeorgiaOffline-debug-apk` как GitHub Actions artifact на 14 дней.

Первый запуск может занять больше времени из-за загрузки и обработки OSM-данных. Обычные сборки используют последнюю проверенную карту из кеша; карта обновляется автоматически раз в неделю или вручную через `Actions → Android CI → Run workflow → refresh_map`. Сеть используется только на стороне CI во время сборки; установленное приложение не загружает карты и не обращается к серверам.

**Важно о языках:** Map Writer записывает стандартное название и имеющиеся значения `name:en`, `name:ru`, `name:ka`. Это не означает, что у каждого объекта есть все три варианта: отсутствующие значения в OSM не создаются автоматически. Текущий Mapsforge reader принимает один preferred language на экземпляр. Переключатель языка выбирает один активный язык, а требуемый режим одновременных многострочных подписей остаётся отдельной задачей.

## Проверки

```bash
python3 scripts/verify_offline_manifest.py
python3 scripts/verify_map_build_config.py
python3 scripts/test_build_poi_database.py
python3 scripts/verify_bundled_map.py
```

Вторая команда выполняется только после генерации карты в CI. Полная проверка APK выполняется workflow через `scripts/verify_apk_bundle.py`.

## История текущих функций

### 0.2.0 — GPS и компас

- GPS по запросу пользователя: WGS84, DMS, точность, GPS-высота, скорость и курс движения.
- Электронный компас через rotation-vector sensor, если он есть на устройстве.
- Копирование координат; локальная метка автомобиля.
- Нет фоновой геолокации и сетевых разрешений.

### 0.3.0 — Mapsforge renderer

- Локальная отрисовка `.map`, масштабирование, панорамирование и масштабная линейка.
- Импорт `.map` через Android Storage Access Framework, копирование во внутреннюю память и проверка bbox.
- Выбор одного предпочтительного языка `en` / `ru` / `ka`.

### 0.4.0 — сборка карты Грузии в CI

- Добавлен сборочный сценарий Mapsforge Map Writer + Osmosis.
- CI формирует `.map` из проверенного Geofabrik PBF или резервного OpenStreetMap France PBF, с `type=hd` и языковыми вариантами `en,ru,ka`.
- Добавлена проверка контрольной суммы исходного PBF, SHA-256 карты и метаданных.
- Добавлено кеширование `.map` в GitHub Actions и проверка фактического содержимого APK.
- Первый успешный CI-run остаётся обязательным подтверждением интеграции на стороне GitHub.

### 0.4.7 — explicit Georgia bbox for Mapsforge Writer

- Исправлен сбой реальной генерации карты: Mapsforge Writer успешно загружался, smoke-test проходил, OSM PBF скачивался и проверялся, но writer завершался с `No valid bounding box found in input data`.
- Для country extract теперь явно задаётся `bbox=41.00,39.95,43.65,46.80` в правильном порядке координат.
- Smoke-test также проверяет явный параметр `bbox`; preflight проверяет оба значения.
- Диапазон рассчитан по крайним координатам Грузии из Geostat Yearbook 2024 с небольшим запасом.
- Android versionName — 0.4.7, versionCode — 11.

### 0.4.6 — корректный OSM XML fixture для Mapsforge smoke-test

- Исправлен тестовый OSM XML: каждый node и way содержит `timestamp` в ISO-8601 UTC, а также `changeset`, `uid`, `user`.
- Предварительная проверка теперь валидирует обязательные атрибуты каждой сущности и формат timestamp до установки Osmosis.
- По логу 0.4.5 подтверждено, что Mapsforge plugin успешно загружен; прежний сбой происходил при чтении тестового XML из-за отсутствующего timestamp.
- Android `versionName` — 0.4.6, `versionCode` — 10.

### 0.4.5 — устойчивое получение OSM и кеш карты

- Добавлен резервный OSM France country extract на случай недоступности Geofabrik.
- PBF загружается с повторами и сверяется с MD5 выбранного источника.
- GitHub Actions восстанавливает последнюю проверенную карту до обращения к внешним источникам.
- Добавлено еженедельное обновление и ручной флаг `refresh_map`; при неудачном обновлении сохраняется предыдущая проверенная карта.
- Android `versionCode` установлен на 9, `versionName` — 0.4.5.

### 0.4.2 — исправление проверки версии Osmosis

- Удалён вызов `osmosis --version`, который приводил к ошибке `Task type version doesn't exist`.
- Версия системного пакета Osmosis теперь считывается через `dpkg-query`.
- Android `versionCode` — 6, `versionName` — 0.4.2.

### 0.4.1 — безопасное обновление карты

- Встроенная карта обновляется автоматически после установки APK с новым SHA-256.
- Карта, импортированная пользователем вручную, не перезаписывается встроенной копией.
- Отключение карты запоминается между запусками приложения.
