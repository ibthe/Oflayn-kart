# Oflayn kart

**Oflayn kart** — автономный атлас Грузии для Android: офлайн-карта, поиск мест, маршруты, навигация, GPS-инструменты и планирование поездок.

Принцип продукта: привычное управление картой, минималистичный интерфейс и работа без сетевых запросов после установки приложения.

## Возможности

### Карта и места
- Локальная карта Mapsforge, подготовленная из OpenStreetMap country extract.
- Светлые и тёмные картографические темы Oflayn Natural, Classic и тематические стили.
- Выбор языка подписей: English, русский или ქართული — один предпочтительный язык за раз.
- Офлайн-каталог POI с поиском по названию, адресу и доступным тегам, быстрыми категориями и поиском в видимой области карты.
- Нажатие на объект карты открывает карточку с доступными сведениями, координатами, сохранением и действием маршрута.
- Избранные места и локальное хранение пользовательских данных.

### Маршруты и навигация
- Построение маршрутов для автомобиля, 4×4, велосипеда и пешком.
- Несколько промежуточных остановок, перестановка и перетаскивание точек маршрута.
- Пошаговая навигация, голосовые подсказки, контроль приближения и перестроение маршрута при отклонении.
- Офлайн-план поездки по дням: добавление мест из каталога и с карты, изменение порядка, перенос между днями, заметки к остановкам и построение маршрута выбранного дня. Ограничение — 20 мест в плане.
- Профиль высот маршрута на основе Copernicus WorldDEM-90: приблизительный набор и сброс высоты, минимум и максимум. Данные имеют разрешение около 90 м и описывают поверхность, включая здания и растительность, а не точную высоту дорожного покрытия.

### Треки и инструменты
- Импорт и экспорт GPX 1.1, включая заметки.
- Запись GPS-трека с фильтрацией неточных и повторных точек, периодическими контрольными сохранениями и восстановлением незавершённой записи.
- Отображение сохранённого трека на карте и обратное ведение по нему.
- GPS-координаты, компас и локальные инструменты.
- SOS-панель: свежие координаты, точность GPS, заряд батареи, копирование и передача сообщения, открытие системного набора номера 112. Приложение не звонит и не отправляет сообщения автоматически.
- Офлайн-путеводитель по восьми регионам Грузии с достопримечательностями, сезонными заметками и предупреждениями о горных дорогах. Это справочная информация, а не источник текущего статуса дорог.

### Хранение карт
- Внутренняя память или подключённая съёмная SD-карта.
- Отображение свободного места и перенос пользовательской карты с проверкой копии до переключения активного пути.
- На SD-карте используется app-specific каталог Android `Android/data/<package>/files/maps`; широкие разрешения на доступ ко всему накопителю не запрашиваются.
- Если SD-карта извлечена, размещённая на ней карта недоступна до повторного подключения или выбора другого накопителя.

## Офлайн-принцип и приватность

- Установленное приложение не загружает карты и POI из сети.
- Нет аккаунтов, рекламы, аналитики и сетевой телеметрии.
- Сеть используется на стороне GitHub Actions для получения исходных картографических и высотных данных во время сборки.
- Геолокация работает в активном приложении; обновления навигации не продолжаются в фоне после ухода приложения с переднего плана.
- Системный набор номера и системное меню «Поделиться» открываются только по явному действию пользователя.

## Источники данных и атрибуция

- **OpenStreetMap** — карта, дороги и POI; лицензия ODbL 1.0. Атрибуция: © OpenStreetMap contributors.
- **Copernicus WorldDEM-90** — высотная модель поверхности с разрешением около 90 м. В приложении указана требуемая атрибуция DLR / Airbus Defence and Space / Copernicus.
- **Mapsforge** — офлайн-рендеринг карт.
- Лицензии библиотек и полные уведомления: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Сборка

Требования: JDK 21, Android SDK Platform 36 / Build Tools 36.0.0, Gradle 9.6.0.

Локальная сборка:

```bash
gradle :app:assembleDebug
```

Локальный APK без подготовленных CI-артефактов может не содержать country map, POI database и DEM tiles. Полный APK формируется GitHub Actions.

Workflow `.github/workflows/android-ci.yml`:
1. Проверяет исходный и объединённый Android manifest на сетевые разрешения.
2. Запускает Python- и Android unit tests.
3. Восстанавливает проверенные OSM map, POI database и road graph из GitHub Actions cache.
4. При необходимости получает и проверяет OSM PBF, извлекает POI (nodes, closed ways и multipolygon relations), строит Mapsforge map и дорожный граф.
5. Получает Copernicus GLO-90 tiles, преобразует их в компактные локальные файлы и проверяет контрольные суммы.
6. Собирает APK и instrumentation APK, затем проверяет наличие карты, POI и DEM внутри APK.

Полная сборка с данными запускается через **Actions → Android CI**. Обычные сборки используют последнюю проверенную пару map/POI и кеш дорожного графа.

## Известные ограничения и следующие этапы

- Контурные линии и hillshade для рельефа ещё не реализованы.
- В дорожном графе ещё предстоит полноценная поддержка turn restrictions и grade-aware routing costs.
- Нужны расширение редакционного путеводителя и дополнительные локальные safety-функции.
- Спутниковые/аэрофотоснимки как отдельный опциональный офлайн-пакет ещё не добавлены.
- Полный uncached end-to-end прогон извлечения POI на country PBF и проверка поисковой релевантности на устройстве ещё требуются.
- Перенос и повторное подключение SD-карты, нехватка свободного места и большие пользовательские карты нужно проверить на физических Android-устройствах.
- Полный визуальный аудит экранов, ориентаций, размеров шрифта, жестов, перекрытий и реальных сценариев навигации выполняется после завершения функционального объёма.
