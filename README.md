# Oflayn kart

**Oflayn kart** — автономный атлас Грузии для Android: офлайн-карта, поиск мест, маршруты, навигация, GPS-инструменты и планирование поездок.

Принцип продукта: привычное управление картой, минималистичный интерфейс и работа без сетевых запросов после установки приложения.

## Возможности

### Карта и места
- Локальная карта Mapsforge, подготовленная из OpenStreetMap country extract.
- Светлые и тёмные темы Oflayn Natural с офлайн-hillshade и отдельным векторным слоем горизонталей, а также Classic и тематические стили.
- Независимое включение подписей на English, русском и ქართულად; доступные языковые варианты объединяются на карте без автоматического перевода. Проверка плотности подписей и производительности на устройствах ещё предстоит.
- Офлайн-каталог POI из OSM nodes, closed ways и multipolygon relations; одноимённые объекты одной категории в радиусе 18 м объединяются с сохранением языковых имён и контактных тегов. Поиск работает по названию, адресу и доступным тегам, есть быстрые категории и поиск в видимой области карты.
- Нажатие на объект карты открывает карточку с доступными сведениями, координатами, сохранением и действием маршрута.
- Избранные места и локальное хранение пользовательских данных.

### Маршруты и навигация
- Построение маршрутов для автомобиля, мотоцикла, 4×4, велосипеда и пешком; мотоциклетный профиль учитывает отдельные OSM access-теги и одностороннее движение, а крутые уклоны из OSM incline tags увеличивают расчётное время.
- Несколько промежуточных остановок, перестановка и перетаскивание точек маршрута.
- Поиск POI в коридоре 2,5 км вдоль построенного маршрута с упорядочиванием результатов по направлению движения и добавлением найденного места как остановки.
- Расширяемая компактная панель навигации: остаток пути и времени, ETA, скорость, курс, координаты и высота по GPS или приблизительной DEM с указанием источника.
- Локальный чек-лист перед поездкой: экипировка, шины, тормоза, свет, топливо, документы, аптечка, офлайн-карта, заряд, экстренный контакт, план поездки и дорожные условия; отметки хранятся только на устройстве.
- После построения маршрута карта автоматически подгоняет обзор и через 7 секунд приближает масштаб; при высокой скорости во время навигации масштаб автоматически отдаляется. Пошаговая навигация, голосовые подсказки, контроль приближения и перестроение маршрута при отклонении.
- Офлайн-план поездки по дням: добавление мест из каталога и с карты, изменение порядка, перенос между днями, заметки к остановкам и построение маршрута выбранного дня. Ограничение — 20 мест в плане.
- Профиль высот маршрута на основе Copernicus WorldDEM-90: приблизительный набор и сброс высоты, минимум и максимум. Данные имеют разрешение около 90 м и описывают поверхность, включая здания и растительность, а не точную высоту дорожного покрытия.

### Треки и инструменты
- Импорт и экспорт GPX 1.1, включая заметки.
- Запись GPS-трека с фильтрацией неточных и повторных точек, периодическими контрольными сохранениями и восстановлением незавершённой записи.
- Отображение сохранённого трека на карте и обратное ведение по нему.
- GPS-координаты, компас, проверка заряда/состояния питания и read-only диагностика доступности сети. Приложение не имеет разрешения INTERNET; статус сети нужен только для информирования, офлайн-функции не зависят от подключения.
- SOS-панель: свежие координаты, точность GPS, заряд батареи, системный набор номера 112 и сохранённый локально экстренный контакт. Можно открыть набор номера контакта или SMS с координатами; приложение не звонит и не отправляет сообщения автоматически.
- Краткая памятка действий при ДТП: безопасность места, вызов 112, ограничение перемещения пострадавшего, базовые меры до прибытия помощи.
- Офлайн-путеводитель по восьми регионам Грузии: подборки мест с переходом к локальному поиску, последовательности остановок, заметки о сервисах, сезонах и горных дорогах. Это справочная информация, а не источник текущего статуса дорог.

### Хранение карт
- Внутренняя память или подключённая съёмная SD-карта.
- Отображение свободного места и перенос пользовательской карты с проверкой копии до переключения активного пути.
- На SD-карте используется app-specific каталог Android `Android/data/<package>/files/maps`; широкие разрешения на доступ ко всему накопителю не запрашиваются.
- Если SD-карта извлечена, размещённая на ней карта недоступна до повторного подключения или выбора другого накопителя.
- Пакеты HGT-рельефа и векторных горизонталей устанавливаются по требованию во внутреннюю память; их размер отображается в разделе «Хранение».

## Офлайн-принцип и приватность

- Установленное приложение не загружает карты и POI из сети.
- Нет аккаунтов, рекламы, аналитики и сетевой телеметрии.
- Сеть используется на стороне GitHub Actions для получения исходных картографических и высотных данных во время сборки.
- Геолокация работает в активном приложении; обновления навигации не продолжаются в фоне после ухода приложения с переднего плана.
- Системный набор номера и системное меню «Поделиться» открываются только по явному действию пользователя.

## Сборка

Требования: JDK 21, Android SDK Platform 36 / Build Tools 36.0.0, Gradle 9.6.0.

Локальная сборка:

```bash
gradle :app:assembleDebug
```

Локальный APK без подготовленных CI-артефактов может не содержать country map, POI database и DEM tiles. Полный APK формируется GitHub Actions.

Workflow `.github/workflows/android-ci.yml`:
1. Проверяет исходный и объединённый Android manifest: сетевой трафик запрещён, разрешено только чтение статуса сети.
2. Запускает Python- и Android unit tests.
3. Восстанавливает проверенные OSM map, POI database и road graph из GitHub Actions cache.
4. При необходимости получает и проверяет OSM PBF, извлекает POI (nodes, closed ways и multipolygon relations), строит Mapsforge map и дорожный граф.
5. Получает Copernicus GLO-90 tiles, создаёт DEM для профиля высот, HGT ZIP для hillshade и отдельную Mapsforge-карту горизонталей; все пакеты проверяются по SHA-256.
6. Собирает APK и instrumentation APK, затем проверяет наличие карты, POI, DEM/HGT и горизонталей внутри APK.

Полная сборка с данными запускается через **Actions → Android CI**. Обычные сборки используют последнюю проверенную пару map/POI и кеш дорожного графа.

## Известные ограничения и следующие этапы

- Опциональный офлайн-спутниковый слой: импорт ZIP-пакета XYZ, проверка лицензии/атрибуции, защита от zip-slip, хранение отдельно от векторной карты и настройка прозрачности. Данные снимков пользователь предоставляет отдельно; приложение не обращается к tile-серверам.
- Полный аудит покрытия POI по стране и поисковой релевантности ещё предстоит; алгоритм дедупликации node/way/relation и relation smoke-тест уже реализованы.
- Дорожный граф учитывает signed incline, разные штрафы движения вверх/вниз, DEM-derived grades из Copernicus GLO-90 там, где OSM incline tags отсутствуют, node-via no_*/only_* restrictions, multi-member no_entry/no_exit, except masks и same-way U-turns. Via-way/conditional restrictions остаются следующими улучшениями.
- Путеводитель и базовые safety-функции расширены; остаются проверка на реальных устройствах, via-way/conditional routing restrictions и полноценная верификация покрытия POI.
- Спутниковые/аэрофотоснимки как отдельный опциональный офлайн-пакет ещё не добавлены.
- Полный uncached end-to-end прогон извлечения POI на country PBF и проверка поисковой релевантности на устройстве ещё требуются.
- Поиск вдоль маршрута и расширяемая панель текущих навигационных данных реализованы; остаётся проверить их в полном UI/маршрутном QA.
- Перенос и повторное подключение SD-карты, нехватка свободного места и большие пользовательские карты нужно проверить на физических Android-устройствах.
- Полный визуальный аудит экранов, ориентаций, размеров шрифта, жестов, перекрытий и реальных сценариев навигации выполняется после завершения функционального объёма.
