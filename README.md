# Georgia Offline 🇬🇪

Полнофункциональный автономный атлас Грузии для Android. Цель проекта — подробная карта всей страны, поиск, маршруты для автомобиля/4×4/велосипеда/пешком, путеводитель, топография, планировщик путешествий и локальные GPS-инструменты.

> **Статус разработки (0.4.3):** подключён Mapsforge renderer; добавлен CI-пайплайн, который получает OpenStreetMap PBF для Грузии (Geofabrik — основной источник, OpenStreetMap France — резервное зеркало), проверяет контрольную сумму, собирает Mapsforge `.map` с языковыми вариантами `en`, `ru`, `ka`, кеширует результат и встраивает его в debug APK. Первый реальный запуск этого workflow ещё должен подтвердить успешную генерацию карты и сборку APK. Встроенная карта при обновлении APK сравнивается по SHA-256 и заменяется в приватном хранилище только если она изменилась; пользовательский импорт не перезаписывается. Сам бинарный файл карты не хранится в исходном ZIP/репозитории: GitHub Actions создаёт его во время сборки.

В приложении уже есть Compose-каркас, локальные настройки языков/тем, экран карты Mapsforge, импорт локального `.map`, GPS-инструменты по явному запросу, электронный компас и метка автомобиля. Маршрутизация BRouter, полная POI-база, DEM/контуры, спутниковый слой, одновременные многострочные подписи и прямое хранение карты на SD-карте ещё не реализованы.

## Принятые решения

- Kotlin + Jetpack Compose.
- Один APK; GitHub Actions формирует и встраивает бинарную карту в `app/src/main/assets/offline/` перед сборкой.
- Приложение не должно запрашивать сетевые разрешения; CI проверяет исходный и объединённый Android manifest.
- Без аккаунта, рекламы, аналитики и сетевой телеметрии.
- Карта готовится из OpenStreetMap country extract для Грузии; основной источник — Geofabrik, резервный — OpenStreetMap France; лицензия данных ODbL 1.0.
- Карта записывает доступные варианты названий `en`, `ru`, `ka`. В текущем UI Mapsforge выбирает один предпочтительный язык; одновременно выводить несколько строк названий пока нельзя. Отсутствующие в OSM языковые варианты не переводятся автоматически.
- Тема приложения: системная / светлая / тёмная. Стили карты: классический / рельеф / автомобильный / велосипедный.
- Внутреннее хранилище по умолчанию; выбор SD-карты через Storage Access Framework уже предусмотрен в UI, но реальное размещение больших файлов на SD-карте ещё требует реализации.

## Открыть и собрать проект

1. Открой папку репозитория `GeorgiaOffline` в Android Studio.
2. Используй JDK 21 (как в CI) и Android SDK Platform 36 / Build Tools 36.0.0.
3. Для локальной сборки без подготовленного файла карты можно выполнить `gradle :app:assembleDebug`; такой APK будет без карты страны.
4. Полная сборка с картой выполняется GitHub Actions после `Push` в `main`/`master` или вручную через Actions → Android CI → Run workflow.

В starter-архив не включён бинарный `gradle-wrapper.jar`. Если Gradle установлен, его можно создать командой `gradle wrapper --gradle-version 9.6.0 --distribution-type bin`. GitHub Actions использует закреплённый Gradle напрямую.

## Полная сборка с офлайн-картой

Workflow `.github/workflows/android-ci.yml` выполняет следующие действия:

1. Устанавливает Android SDK Platform 36 и JDK 21.
2. Проверяет отсутствие сетевых и фоновых location-разрешений.
3. Сначала восстанавливает последнюю проверенную карту из GitHub Actions cache.
4. Если карты ещё нет, запрошено обновление или выполняется еженедельное обновление, скачивает OSM PBF: сначала Geofabrik, затем резервное зеркало OpenStreetMap France. PBF проверяется по MD5 того же источника.
5. Устанавливает Osmosis (версия пакета читается через `dpkg-query`, без `osmosis --version`) и собирает Mapsforge Map Writer.
6. Создаёт `georgia.map` с параметрами `preferred-languages=en,ru,ka` в дисковом режиме `type=hd`.
7. Проверяет файл карты и метаданные SHA-256, кеширует бинарные assets. При сбое обновления сохраняет уже проверенную кешированную карту.
8. Собирает APK, проверяет, что карта действительно находится внутри APK, и повторно проверяет итоговый manifest.
9. Публикует `GeorgiaOffline-debug-apk` как GitHub Actions artifact на 14 дней.

Первый запуск может занять больше времени из-за загрузки и обработки OSM-данных. Обычные сборки используют последнюю проверенную карту из кеша; карта обновляется автоматически раз в неделю или вручную через `Actions → Android CI → Run workflow → refresh_map`. Сеть используется только на стороне CI во время сборки; установленное приложение не загружает карты и не обращается к серверам.

**Важно о языках:** Map Writer записывает стандартное название и имеющиеся значения `name:en`, `name:ru`, `name:ka`. Это не означает, что у каждого объекта есть все три варианта: отсутствующие значения в OSM не создаются автоматически. Текущий Mapsforge reader принимает один preferred language на экземпляр. Переключатель языка выбирает один активный язык, а требуемый режим одновременных многострочных подписей остаётся отдельной задачей.

## Проверки

```bash
python3 scripts/verify_offline_manifest.py
python3 scripts/verify_bundled_map.py
```

Вторая команда выполняется только после генерации карты в CI. Полная проверка APK выполняется workflow через `scripts/verify_apk_bundle.py`.

## История текущих функций

### 0.2.0 — GPS и компас

- GPS по запросу пользователя: WGS84, DMS, точность, GPS-высота, скорость и курс движения.
- Электронный компас через rotation-vector sensor, если он есть на устройстве.
- Копирование координат; локальная метка автомобиля.
- Нет фоновой геолокации и сетевых разрешений.

### 0.3.0 — Mapsforge renderer

- Локальная отрисовка `.map`, масштабирование, панорамирование и масштабная линейка.
- Импорт `.map` через Android Storage Access Framework, копирование во внутреннюю память и проверка bbox.
- Выбор одного предпочтительного языка `en` / `ru` / `ka`.

### 0.4.0 — сборка карты Грузии в CI

- Добавлен сборочный сценарий Mapsforge Map Writer + Osmosis.
- CI формирует `.map` из проверенного Geofabrik PBF или резервного OpenStreetMap France PBF, с `type=hd` и языковыми вариантами `en,ru,ka`.
- Добавлена проверка контрольной суммы исходного PBF, SHA-256 карты и метаданных.
- Добавлено кеширование `.map` в GitHub Actions и проверка фактического содержимого APK.
- Первый успешный CI-run остаётся обязательным подтверждением интеграции на стороне GitHub.

### 0.4.3 — устойчивое получение OSM и кеш карты

- Добавлен резервный OSM France country extract на случай недоступности Geofabrik.
- PBF загружается с повторами и сверяется с MD5 выбранного источника.
- GitHub Actions восстанавливает последнюю проверенную карту до обращения к внешним источникам.
- Добавлено еженедельное обновление и ручной флаг `refresh_map`; при неудачном обновлении сохраняется предыдущая проверенная карта.
- Android `versionCode` увеличен до 7, `versionName` — до 0.4.3.

### 0.4.2 — исправление проверки версии Osmosis

- Удалён вызов `osmosis --version`, который приводил к ошибке `Task type version doesn't exist`.
- Версия системного пакета Osmosis теперь считывается через `dpkg-query`.
- Android `versionCode` — 6, `versionName` — 0.4.2.

### 0.4.1 — безопасное обновление карты

- Встроенная карта обновляется автоматически после установки APK с новым SHA-256.
- Карта, импортированная пользователем вручную, не перезаписывается встроенной копией.
- Отключение карты запоминается между запусками приложения.
