GEORGIA OFFLINE — ПОЛНОЕ ОБНОВЛЕНИЕ РЕПОЗИТОРИЯ

Этот ZIP содержит весь текущий исходный проект. Файлы внутри архива уже лежат
по правильным путям, включая скрытую папку .github.

ЧТО ДЕЛАТЬ

1. Откройте GitHub Desktop и выберите ваш репозиторий GeorgiaOffline
   (или тот локальный репозиторий, куда вы ранее клонировали проект).
2. Выберите Repository → Show in Finder (Mac) или Show in Explorer (Windows).
3. Рекомендуется сначала скопировать текущую папку репозитория в резервное место.
4. Распакуйте этот ZIP.
5. ВАЖНО ДЛЯ macOS: в открытой распакованной папке нажмите Command + Shift + .
   (точка), чтобы показать скрытые элементы. Убедитесь, что видите папку .github.
   В Windows включите «Вид → Показать → Скрытые элементы».
6. Скопируйте ВСЁ содержимое распакованной папки прямо в корень вашего репозитория.
   Не копируйте внешнюю папку целиком внутрь репозитория.
7. Согласитесь объединить папки и заменить одноимённые файлы.
8. Убедитесь, что вместе с остальными файлами скопировалась папка .github.
   В ней находится workflows/android-ci.yml — файл автоматической сборки.
9. Вернитесь в GitHub Desktop. В разделе Changes появятся изменённые файлы.
10. В поле Summary напишите: Fix Android SDK platform 36 build.
11. Нажмите Commit to main, затем Push origin.
11. На GitHub откройте вкладку Actions и проверьте новую сборку.

ВАЖНО

• В этом ZIP нет служебной папки .git, поэтому история Git не перезаписывается.
• Если GitHub Desktop показывает много изменений — это нормально: ZIP содержит
  весь проект, а не только один исправленный файл.
• Если сборка снова станет красной, скачайте полный лог Actions и отправьте его.
• В этом пакете устранена конкретная ошибка SDK Platform 37. Успешная сборка APK
  ещё не подтверждена, пока новый запуск Actions не завершится зелёным.
