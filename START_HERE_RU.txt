GEORGIA OFFLINE — ПОЛНОЕ ОБНОВЛЕНИЕ РЕПОЗИТОРИЯ

Этот ZIP содержит весь текущий исходный проект. Файлы внутри архива уже лежат
по правильным путям, включая скрытую папку .github.

ЧТО ДЕЛАТЬ

1. Откройте GitHub Desktop и выберите ваш репозиторий GeorgiaOffline
   (или тот локальный репозиторий, куда вы ранее клонировали проект).
2. Выберите Repository → Show in Finder (Mac) или Show in Explorer (Windows).
3. Рекомендуется сначала скопировать текущую папку репозитория в резервное место.
4. Распакуйте этот ZIP.
5. ВАЖНО ДЛЯ macOS: в открытой распакованной папке нажмите Command + Shift + .
   (точка), чтобы показать скрытые элементы. Убедитесь, что видите папку .github.
   В Windows включите «Вид → Показать → Скрытые элементы».
6. Скопируйте ВСЁ содержимое распакованной папки прямо в корень вашего репозитория.
   Не копируйте внешнюю папку целиком внутрь репозитория.
7. Согласитесь объединить папки и заменить одноимённые файлы.
8. Убедитесь, что вместе с остальными файлами скопировалась папка .github.
   В ней находится workflows/android-ci.yml — файл автоматической сборки.
9. Вернитесь в GitHub Desktop. В разделе Changes появятся изменённые файлы.
10. В поле Summary напишите: Fix AndroidX dependencies for API 36.
11. Нажмите Commit to main, затем Push origin.
12. На GitHub откройте вкладку Actions и проверьте новую сборку.

ВАЖНО

• В этом ZIP нет служебной папки .git, поэтому история Git не перезаписывается.
• Если GitHub Desktop показывает много изменений — это нормально: ZIP содержит
  весь проект, а не только один исправленный файл.
• Если сборка снова станет красной, скачайте полный лог Actions и отправьте его.
• В этом пакете исправлена несовместимость AndroidX-зависимостей с API 36. Успешная сборка APK
  ещё не подтверждена, пока новый запуск Actions не завершится зелёным.

СОСТОЯНИЕ ПРОЕКТА

Это Android starter-проект с базовым интерфейсом, локальными настройками и CI.
Полная векторная карта Грузии, реальная офлайн-маршрутизация и полный каталог
точек интереса ещё не встроены.


ПОСЛЕДНЕЕ ИСПРАВЛЕНИЕ

Предыдущая сборка упала на проверке 12 AAR: Compose 1.12.1 и Lifecycle 2.11.0
требовали Android API 37, а проект использует API 36. В этом обновлении согласованы
версии Compose BOM 2026.03.00, Activity Compose 1.11.0 и Lifecycle 2.10.0.


ИСПРАВЛЕНИЕ ОШИБКИ №4
В этой версии исправлен конфликт Kotlin/JVM в настройках темы. Функции изменения темы теперь называются updateAppTheme и updateMapTheme. Просто скопируйте всё содержимое этого архива в папку репозитория с заменой файлов.

КАК ПРАВИЛЬНО ОБНОВИТЬ ПРОЕКТ
1. Закройте/оставьте GitHub Desktop открытым и выберите репозиторий GeorgiaOffline.
2. Repository → Show in Finder (Mac) или Show in Explorer (Windows).
3. Распакуйте архив. Внутри архива уже находятся папки и файлы, начинающиеся с точки, включая .github.
4. Выделите ВСЁ содержимое распакованной папки и скопируйте прямо в папку репозитория. Не копируйте внешнюю папку архива целиком.
5. Подтвердите объединение папок и замену файлов. На Mac в Finder нажмите Command+Shift+. чтобы видеть скрытые файлы.
6. Вернитесь в GitHub Desktop, создайте Commit и нажмите Push origin.
Не удаляйте папку .git — в архиве её нет.


ИСПРАВЛЕНИЕ ОШИБКИ №5
В GitHub Actions приложение и тесты уже скомпилировались. Не прошёл один тест: в списке функций автомобильного модуля не было отдельной строки про 4×4 (она была только в описании). В этой версии добавлен отдельный пункт 4×4, а проверка теста охватывает пеший, велосипедный, автомобильный и внедорожный режимы.

Для обновления распакуйте этот архив и скопируйте ВСЁ его содержимое прямо в корень папки GeorgiaOffline с заменой файлов. Обязательно сохраните скрытую папку .github. Затем сделайте Commit и Push в GitHub Desktop.
