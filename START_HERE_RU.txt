GEORGIA OFFLINE — ПОЛНЫЙ ПАКЕТ РЕПОЗИТОРИЯ 0.5.5

ВАЖНО: этот ZIP содержит ВСЕ исходные файлы проекта по правильным путям, включая скрытую папку .github. В нём нет служебной папки .git. Бинарная карта Грузии не лежит в ZIP: GitHub Actions автоматически получает её и встраивает в APK во время сборки.

КАК ОБНОВИТЬ ПРОЕКТ

1. Открой GitHub Desktop и выбери репозиторий GeorgiaOffline.
2. Выбери Repository → Show in Finder (Mac) или Show in Explorer (Windows).
3. Сначала сделай резервную копию папки репозитория, если в ней есть свои изменения.
4. Распакуй этот ZIP.
5. На Mac в Finder нажми Command + Shift + . (точка), чтобы увидеть скрытую папку .github. В Windows включи «Показать скрытые элементы».
6. Открой распакованную папку и скопируй ВСЁ её содержимое прямо в корень папки репозитория. Не копируй внешнюю папку ZIP внутрь проекта.
7. Подтверди объединение папок и замену одноимённых файлов. Проверь, что папка .github тоже скопировалась.
8. Вернись в GitHub Desktop. В Summary напиши: Update Georgia Offline to 0.5.5 fix POI extraction memory.
9. Нажми Commit to main, затем Push origin.

ЧТО БУДЕТ ПОСЛЕ PUSH

1. GitHub откроет вкладку Actions и запустит Android CI.
2. Workflow проверит исходный Android manifest, конфигурацию карты, unit tests и повторное использование PBF cache.
3. Workflow сначала пытается восстановить последнюю проверенную карту. Если карта отсутствует или запрошено обновление, он восстанавливает ранее проверенный PBF из отдельного кеша либо скачивает его: Geofabrik используется первым, OpenStreetMap France — как резервный источник `georgia.osm.pbf`; его checksum имеет точное имя `georgia.osm.pbf.md5`. Файл проверяется по MD5 и сразу сохраняется в Actions cache до дальнейшей обработки. Затем опубликованный Mapsforge Map Writer 0.25.0 и Osmosis создают Mapsforge `georgia.map`. Writer собирается отдельным небольшим Gradle-проектом из Maven Central; Android/sample-проекты Mapsforge не конфигурируются. Затем JAR добавляется в `/usr/share/osmosis/`, регистрируется в `/etc/osmosis/plexus.conf` и проверяется реальной тестовой записью `.map`. Каждый node и way в smoke-test содержит обязательный `timestamp` и стандартные метаданные OSM.
4. Карта, SQLite-справочник POI и сведения о них (SHA-256, источник, дата, лицензия) будут включены в APK.
5. После успешной сборки в Actions появится Artifact GeorgiaOffline-debug-apk. Его можно скачать, распаковать и установить APK на Android.

ПЕРВАЯ СБОРКА

Первый запуск может быть дольше обычного, потому что создаёт карту из открытых данных Грузии. Обычные сборки используют кеш последней проверенной карты и исходного PBF. Если сборка карты будет отменена, следующий запуск сможет продолжить работу без повторного скачивания PBF. Workflow не отменяет текущий запуск автоматически при новом push. Обновление выполняется еженедельно; вручную его можно запустить в Actions → Android CI → Run workflow → refresh_map. Сеть используется только GitHub Actions во время сборки. Установленное приложение не должно запрашивать разрешение INTERNET и не обращается к картографическим серверам.

ВАЖНЫЕ ОГРАНИЧЕНИЯ ВЕРСИИ 0.5.4

• Mapsforge хранит доступные языковые варианты en/ru/ka, но не создаёт переводы там, где OSM не содержит соответствующих тегов.
• Текущий экран карты отображает один выбранный предпочтительный язык за раз. Одновременные многострочные подписи всех включённых языков будут следующим этапом.
• Локальная POI SQLite-база и поиск по названиям, адресам, телефонам, сайтам и часам работы добавлены; пока индексируются OSM nodes и closed ways, но не relation-only POI. Офлайн-маршрутизация, DEM, высотные профили, спутниковый слой и запись GPX ещё разрабатываются.
• Перед копированием встроенной карты приложение проверяет свободное место. Выбор папки SD-карты пока сохраняет URI; полноценное хранение больших карт прямо на SD подключим отдельно.
• Встроенная карта обновляется по SHA-256 при обновлении APK; импортированная вручную карта не перезаписывается. Отключение карты можно отменить кнопкой «Включить встроенную карту».
• ZIP не содержит готовый APK. APK создаётся в GitHub Actions. В него должны попасть georgia.map и georgia-poi.sqlite.
• Устранена ошибка CI `Task type version doesn't exist`: workflow больше не вызывает `osmosis --version`, а получает версию Debian-пакета через dpkg-query.
• Резервное зеркало использует существующую пару `georgia.osm.pbf` + `georgia.osm.pbf.md5`.
• Сборка Mapsforge Writer изолирована от полного Android/sample multi-project; JAR явно добавляется в Debian Plexus classpath и проверяется реальным smoke-test перед загрузкой полной карты.

ЕСЛИ СБОРКА УПАЛА

В GitHub открой Actions → последний красный Android CI → скачай полный лог запуска и отправь его сюда ZIP-архивом. Не нужно вручную менять код.

ПАПКА .GITHUB

Не пропускай .github: в ней находится workflows/android-ci.yml — автоматический сценарий, который формирует карту и собирает APK. Не удаляй локальную папку .git — в исходном ZIP её нет.

ИСПРАВЛЕНИЕ 0.4.6

Предыдущий GitHub Actions run подтвердил, что Mapsforge Writer уже загружался: в журнале появилась строка `mapfile-writer version: mapsforge-map-writer-0.25.0`. Сбой был в тестовом OSM XML: отсутствовал timestamp у сущностей. В новой версии fixture исправлен, а preflight заранее проверяет timestamp, changeset, uid и user у каждого node/way.


ИСПРАВЛЕНИЕ 0.4.7

Новый GitHub Actions run подтвердил, что Android unit tests прошли, OSM PBF Грузии был скачан и проверен, а Mapsforge Writer 0.25.0 успешно зарегистрировался и создал тестовую карту. Ошибка полной генерации была только в том, что у PBF-зеркала отсутствовал пригодный bbox в заголовке. В новой версии команда Map Writer всегда передаёт явную область Грузии `41.00,39.95,43.65,46.80`; smoke-test тоже упражняет параметр bbox.


ОБНОВЛЕНИЕ 0.5.4 — ПРОГРЕСС ИЗВЛЕЧЕНИЯ POI

GitHub Actions устанавливает PyOsmium, запускает unit tests и smoke-test извлечения из небольшого OSM XML. Во время сборки из того же проверенного PBF создаётся SQLite-база georgia-poi.sqlite: еда, жильё, достопримечательности, медицина, транспорт, сервисы, магазины, история, природа и населённые пункты. Экран «Места» ищет по сохранённым вариантам English, Russian и Georgian, показывает включённые названия и позволяет скопировать координаты. В карточках также отображаются адрес, телефон, сайт, часы работы, кухня и доступность, если эти теги есть в OSM; поиск учитывает часть этих полей. База проверяется по SHA-256 и SQLite integrity, затем упаковывается в APK рядом с georgia.map. Relation-only POI не включены, а отсутствующие переводы не генерируются.


ИЗМЕНЕНИЕ В ВЕРСИИ 0.5.4
В Ubuntu 26.04 пакет PyOsmium называется python3-pyosmium. В workflow исправлено имя apt-пакета; Python-модуль по-прежнему импортируется командой import osmium. Установку выполняет GitHub Actions автоматически.


НОВОЕ В 0.5.4
- Извлечение POI из PBF теперь печатает прогресс каждые 250 000 OSM-сущностей или каждые 15 секунд.

- Это не исправляет внешнюю отмену runner, но позволяет отличить медленный процесс от зависания.
