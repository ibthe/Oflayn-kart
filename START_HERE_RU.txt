GEORGIA OFFLINE — ИНСТРУКЦИЯ ДЛЯ ОБНОВЛЕНИЯ РЕПОЗИТОРИЯ

ВАЖНО: содержимое этого ZIP подготовлено для копирования ПРЯМО В КОРЕНЬ
уже существующей локальной папки репозитория GeorgiaOffline.

1. Откройте GitHub Desktop.
2. Выберите репозиторий GeorgiaOffline.
3. Откройте Repository -> Show in Finder (macOS) или Show in Explorer (Windows).
4. Сделайте резервную копию папки репозитория, если в ней есть собственные изменения.
5. Распакуйте этот ZIP и скопируйте ВСЁ его содержимое прямо в открытую папку
   репозитория. Не создавайте дополнительную вложенную папку GeorgiaOffline.
6. Согласитесь объединить папки и заменить совпадающие файлы.
7. Убедитесь, что вместе с остальными файлами скопировалась скрытая папка
   .github (внутри неё находится workflows/android-ci.yml).
8. Вернитесь в GitHub Desktop: изменения появятся в списке Changes.
9. Введите краткое описание, например "Update GeorgiaOffline starter", и нажмите
   Commit to main. Затем нажмите Push origin.

В ZIP нет папки .git: история и настройки вашего локального репозитория не
затрагиваются. Пути внутри архива уже соответствуют путям проекта.

СОСТОЯНИЕ ПРОЕКТА
Это полный текущий исходный каркас Android-приложения и CI-конфигурация.
Реальные данные подробной карты Грузии, автономный поиск по полной базе,
интегрированная маршрутизация и полный каталог POI пока не включены. Не считайте
этот пакет готовым автономным навигатором или готовым APK.
