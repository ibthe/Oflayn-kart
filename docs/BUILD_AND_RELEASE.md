# Сборка и выпуск

## Автоматическая сборка на GitHub Actions

Workflow `.github/workflows/android-ci.yml` запускается при push в `main`/`master`, pull request или вручную (`workflow_dispatch`). Он использует Ubuntu, JDK 21, Android SDK Platform 36, Build Tools 36.0.0 и Gradle 9.6.0.

### Что происходит в полной CI-сборке 0.4.3

1. Проверяется исходный `AndroidManifest.xml` на сетевые и фоновые location-разрешения.
2. Запускаются unit tests.
3. Workflow пытается восстановить последнюю проверенную карту Грузии из GitHub Actions cache. Кеш восстанавливается до любых сетевых обращений к картографическим источникам.
4. Если карты нет в кеше, запрошено ручное обновление или запущено еженедельное расписание, workflow устанавливает Osmosis, собирает Mapsforge Map Writer 0.25.0 и готовит новую карту.
5. Geofabrik — основной источник PBF. При недоступности Geofabrik используется резервное зеркало OpenStreetMap France. Оба варианта скачиваются с повторами и обязательно проверяются по MD5 поставщика; повреждённый файл не передаётся Map Writer.
6. Mapsforge создаёт `.map` с `preferred-languages=en,ru,ka` в режиме `type=hd`. Новый файл сначала создаётся как временный; предыдущая проверенная карта заменяется только после базовой проверки нового файла.
7. Проверяются размер, языковые метаданные и SHA-256 карты. Успешно собранная карта сохраняется в GitHub Actions cache. Если обновление не удалось, но уже есть проверенная кешированная карта, workflow оставляет её и продолжает сборку с предупреждением.
8. Gradle собирает APK, затем отдельные скрипты проверяют, что карта действительно включена в APK и checksum совпадает. Проверяется итоговый merged manifest, затем APK публикуется в Artifacts на 14 дней.

Обычные push-сборки используют последнюю проверенную карту из кеша и не обращаются к OSM-источникам, пока карта доступна. Обновление карты автоматически запускается раз в неделю. Чтобы принудительно обновить карту вручную, открой Actions → Android CI → Run workflow и включи `refresh_map`.

**Важно:** OpenStreetMap France группирует выгрузку страны Georgia в каталоге `asia`. Это всё равно страна Georgia на Кавказе, а не американский штат Georgia. Резервное зеркало может отставать от Geofabrik по дате обновления; фактически использованный провайдер и MD5 записываются в `georgia-map-build.json`.

GitHub Actions использует интернет только во время сборки для получения открытых исходных данных и зависимостей. Установленное приложение не получает разрешение `INTERNET` и не обращается к картографическим серверам.

## Где скачать APK

1. Открой репозиторий на GitHub.
2. Перейди во вкладку **Actions**.
3. Открой последний зелёный запуск **Android CI**.
4. Внизу страницы найди **Artifacts** и скачай `GeorgiaOffline-debug-apk`.
5. Распакуй скачанный artifact ZIP и установи APK на Android. Для debug-сборки Android может показать стандартное предупреждение о неизвестном источнике установки.

Если Actions завершился красным, скачай полный лог конкретного workflow run и отправь ZIP с логами — не нужно вручную редактировать код.

## Локальная сборка

Требуются Android Studio, Android SDK Platform 36, Build Tools 36.0.0 и JDK 17 или новее. Локальная сборка из чистого исходного ZIP не содержит бинарный `georgia.map`, потому что карта генерируется в CI. При обновлении приложения встроенный файл сравнивается с SHA-256 из `georgia-map-build.json`; он заменяется только если данные изменились. Пользовательская карта, импортированная вручную, не перезаписывается. Для полной локальной сборки сначала выполни `scripts/install_mapsforge_writer.sh` и `scripts/build_georgia_map.sh`, затем: `gradle :app:testDebugUnitTest :app:assembleDebug`.

## Один APK и размер

Карта `.map` генерируется в `app/src/main/assets/offline/` до Gradle build. Формат `.map` добавлен в `noCompress`, чтобы не хранить вторую ZIP-сжатую копию во время установки/копирования. Итоговый APK будет больше минимального приложения на размер векторной карты плюс другие assets, которые появятся позже. Перед добавлением POI, DEM, спутниковых снимков и routing graph необходимо контролировать размер APK и свободное место устройства.

## Подпись release APK

Debug APK подходит для тестирования. Для постоянных обновлений нужна своя release keystore, хранящаяся только в GitHub Actions Secrets: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD`. Не помещай keystore и пароли в репозиторий, Issues или логи.
