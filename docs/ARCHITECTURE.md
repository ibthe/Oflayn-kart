# Архитектура Georgia Offline

```text
Compose UI
  ├── Map / Discover / Route / Saved / Tools / Settings
  └── local settings
       ├── MapRenderer ── Mapsforge adapter
       ├── PoiRepository ── local SQLite substring search
       ├── OfflineRouter ── planned BRouter integration
       ├── ElevationProvider ── planned local DEM / hillshade
       ├── TrackRecorder ── planned Android Location + SensorManager
       ├── UserRepository ── planned local SQLite/Room
       └── StorageBackend ── app-private storage; SAF SD-card backend planned

GitHub Actions data pipeline
  ├── Geofabrik primary / OSM France fallback Georgia country PBF + MD5 verification
  ├── Osmosis + Mapsforge Map Writer (pinned 0.25.0)
  ├── mapsforge .map with preferred language variants en/ru/ka
  ├── PyOsmium -> SQLite POI database (nodes + closed ways)
  ├── SHA-256 build manifest for map + POI database
  └── cached assets -> app/src/main/assets/offline/

APK assets
  ├── Georgia vector map (.map) — generated by CI in v0.4.0
  ├── POI + multilingual names (.sqlite) — generated from the same OSM PBF
  ├── route graph/segments and profiles — planned
  ├── DEM / contours / hillshade — planned
  ├── optional satellite mosaic — planned
  └── data-manifest.json + license notices
```

## Key decisions

- The installed app has no network permission and no network tile source.
- Map data are generated during CI, not downloaded by the installed app.
- One APK is the selected distribution format; the map binary is placed in Android assets before Gradle packaging.
- `PoiRepository` copies the SQLite POI asset to app-private storage after checking SHA-256 and database row availability; local search uses parameterized SQL and the normalized multilingual `search_text` field.
- `MapFileRepository` copies the uncompressed map asset to app-private storage for random access and validates that the map bounding box intersects Georgia. It compares the embedded SHA-256 build manifest and refreshes the bundled copy after an app update only when the map changed. User-imported files are tracked separately and are not overwritten; importing one also clears the bundled-map hash marker so the restore action copies the APK asset again.
- The CI restores the most recent verified country-map cache before contacting OSM providers. When a refresh is requested or the cache is missing, Geofabrik is tried first and the OpenStreetMap France Georgia-country mirror is the fallback. Each downloaded PBF is checked against that provider’s MD5. The exact provider and checksum are recorded in the map build manifest. Weekly scheduled and manual refreshes update the cache; normal code pushes use the last verified map.
- The source ZIP does not include the large binary map. It is generated by GitHub Actions and ends up in the APK artifact.
- Mapsforge is the map renderer and map format. BRouter routing is not yet integrated.
- Language variants are requested from the writer as `en,ru,ka`; a name variant is stored only if the corresponding OSM tag exists. There is no automatic translation. The current reader displays one preferred language at a time, not stacked multi-language labels.
- The SD-folder picker is present, but direct map extraction to external SAF storage is not implemented yet. An explicit map-disable setting is persisted across launches, users can restore the APK-bundled map, and the repository checks free space before copying a large asset.

## GPS tools (0.2.0)

`ToolsScreen` uses Android `LocationManager` with `GPS_PROVIDER` only after the user taps the GPS start action and grants location permission. Updates are removed when the screen leaves composition or GPS is stopped. The implementation does not request background location or internet access. Compass azimuth uses `Sensor.TYPE_ROTATION_VECTOR`; the local car marker is stored in app-private SharedPreferences. Coordinate formatting is isolated in `GeoFormatting` and covered by unit tests.

## Mapsforge renderer (0.3.0)

- Android dependencies: `org.mapsforge:mapsforge-map-android:0.25.0` and `org.mapsforge:mapsforge-themes:0.25.0`.
- `MapsforgeMapSurface` hosts native `MapView` inside Compose using `AndroidView`. It uses a local `MapFile`, a tile cache and `TileRendererLayer`; no online tile source is configured.
- Local `.map` import uses Android Storage Access Framework and validates Mapsforge header plus Georgia bounding-box intersection.
- `MapFileRepository.installBundledMap` copies the CI-generated APK asset to app-private storage on first run.

## Georgia map generation (0.4.0)

- `scripts/install_mapsforge_writer.sh` checks Osmosis, clones the pinned Mapsforge 0.25.0 source tag, builds the `mapsforge-map-writer:fatJar` task and installs the plugin for the current CI user.
- `scripts/build_georgia_map.sh` retrieves the Geofabrik Georgia country PBF (with OpenStreetMap France fallback) and matching provider MD5, verifies the source, runs `build_poi_database.py` using PyOsmium's disk-backed node-location index to create a SQLite POI database from OSM nodes and closed ways, then runs Osmosis `--rb` -> `--mw` using `type=hd`, start position near Tbilisi, start zoom 9, and `preferred-languages=en,ru,ka`.
- The resulting `georgia.map`, `georgia-poi.sqlite` and `georgia-map-build.json` (source, timestamp, source MD5, SHA-256/size/count for both assets, writer version, ODbL attribution) are cached and copied into APK assets.
- `verify_bundled_map.py` checks the map SHA-256, SQLite integrity/row count and POI SHA-256 before Android build; `verify_apk_bundle.py` reopens the produced APK and confirms that both data assets inside it match the manifest.
- `verify_offline_manifest.py --include-merged` verifies the final merged manifest after Gradle assembly.

## POI database and local search (0.5.3)

- The same verified country PBF is parsed by PyOsmium using `locations=True` and `dense_mmap_array` (disk-backed node-location index).
- POI records include OSM nodes and closed ways, categories, coordinates, OSM tags and `name` / `name:en` / `name:ru` / `name:ka` values where present. Relation-only POIs are not yet included.
- `PoiRepository` validates the generated SQLite asset with SHA-256, copies it to app-private storage, and runs local parameterized SQL search. Selected name variants can be shown together in the results list.
- The POI search index also includes public OSM address, phone, website, opening-hours, cuisine, wheelchair-access and operator/brand tags. The detail card displays only fields actually present in the source.
- The index intentionally uses ordinary SQLite `instr()` over a normalized text field rather than requiring FTS5 on every Android system.
- Public address/contact/business tags (address, phone, website, opening hours, cuisine, wheelchair, internet, operator and brand) are searchable and shown on a POI card when present. `opening_hours` is displayed as source text, not interpreted as live opening status.

## POI extraction progress (0.5.4)

PyOsmium emits progress heartbeats every 250,000 OSM entities or 15 seconds. This is diagnostic output only and does not change POI selection or the database schema.
